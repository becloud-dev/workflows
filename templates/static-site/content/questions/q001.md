  type: single-choice
  question_text: >-
    A law firm needs an AI solution that reads long legal documents and extracts key points without
    custom machine learning training. Which solution fits?
  options:
    - { id: A, text: Build a named-entity recognition system in a custom ML platform. }
    - { id: B, text: Use a summarisation application built on managed foundation models. }
    - { id: C, text: Create a recommendation engine. }
    - { id: D, text: Develop a multi-language translation pipeline. }
  correct: B
  rationale:
    summary: Summarisation is a core capability of foundation models and needs no custom training.
    breakdown:
      A: Entity recognition extracts names and dates but does not summarise, and needs custom setup.
      B: Managed foundation models summarise text out of the box.
      C: Recommendation engines suit user preferences, not documents.
      D: Translation does not summarise or extract key points.
